PLACEWISE — STUDENT PLACEMENT MANAGEMENT FRONTEND

Run:
1. Extract this ZIP.
2. Open index.html in a browser (Chrome recommended).

This is frontend only: HTML, CSS and vanilla JavaScript. It uses sample records
based on the supplied MySQL/MongoDB schema:
Student, Company, Placement_Drive, Internship, Skill, Student_Skill,
Application, Placement and Application_Audit.

Included screens:
- Overview dashboard
- Students directory with search and filters
- Placement drives and eligibility display
- Internship listings
- Application tracker
- Placements
- Company directory

Demo interactions:
- Navigation between screens
- Search and filter records
- Apply modal with a basic CGPA check
- Add-student demo form
- CSV export

IMPORTANT:
No backend/API/database connection is included, as requested. The records are
hard-coded in app.js and changes are temporary in the browser session.
To connect it later, replace the arrays in app.js with fetch() calls to your API.
