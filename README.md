STUDENT PLACEMENT MANAGEMENT SYSTEM

Folder guide:
- frontend/: static website files (index.html, styles.css, app.js).
- database/: SQL schema/sample data and MongoDB setup/query script.

GitHub upload:
1. Extract this ZIP on your device.
2. Open your GitHub repository.
3. Choose Add file > Upload files (or the "uploading an existing file" link).
4. Upload the contents of this folder, preserving the frontend/ and database/ folders.
5. Commit changes.

Important: The supplied frontend is currently a static demo and uses sample data in app.js. The SQL and MongoDB scripts are database setup scripts; they are not a running backend/API server and are not automatically connected to the webpage. GitHub Pages can host the static frontend only. A server/API and hosted database connection are needed for live database-backed functionality.
